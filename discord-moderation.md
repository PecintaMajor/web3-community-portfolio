# Discord Moderation

## Moderation Principles

- Be respectful
- Stay neutral during conflicts
- Apply rules consistently
- Protect members from spam and scams
- Escalate serious issues to the appropriate team

## Example Workflow

**Message reported → Review context → Apply community rules → Respond → Escalate if necessary → Document**

## Moderator Checklist

- [ ] Check reports
- [ ] Monitor active channels
- [ ] Remove obvious spam/scams
- [ ] Help members with questions
- [ ] Check announcements
- [ ] Report important issues to the team
